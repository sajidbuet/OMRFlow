## 4. Qualification architecture

```text
 supervisor (CLI process; never killed)
   plans the cohort + ground truth (cohort.py, reference.py) -> manifest.json
   renders the pool with the synthetic sheet generator (render.py)
   builds the project through production services (project.py)
   reads the database read-only from outside (inspect.py); own fsynced log
   |
   +-- writer A / B / C   separate processes, one per scanner; copy pool bytes into
   |                      disk/Scanner_X by write pattern; log write_started /
   |                      write_completed (size, SHA-256), fsynced
   |                      share/Scanner_X = a junction to disk/Scanner_X = the watched root
   |
   +-- coordinator        the application under test, a separate process killed with
                          TerminateProcess: ContinuousEngine + ProcessRecogniser
                          (real worker processes, Job Object) + IntakeService, and the
                          scripted operator thread (operator.py, production services only);
                          logs claimed (before submission) / committed / decisions /
                          heartbeat; obeys hold, release, arm, disarm, close, finish,
                          reopen, release_held, downstream, reprocess, stop
 evaluator (assertions.py): the 16 assertions, crash cases 1-15, endurance A-E, the verdict
 report generator (report.py): report.json + report.md, from the machine-readable results
```

* **External evidence**: every writer, coordinator and supervisor event is a
  JSON line with the campaign id, role and pid, fsynced; a reader refuses a
  line of another campaign. Durable facts are read read-only from the project
  database after rolling back a hot journal exactly as the next open would.
* **Kill points are state-based**: committed fraction plus at least two
  sheets `processing` for the percentage kills; coordinator pause points for
  "after a commit", "commit whose duplicate pass is owed", "after the
  operator's n-th decision" and, from 95 %, "a commit reaching the target with
  other sheets still in a worker, or a sheet handed to a worker once the
  target is reached"; a clean close with work in flight.
* **Operator actor**: decides from the paper's truth (never from the
  application's reading) through `review_store`, `quality_decisions`,
  `scan_lifecycle`, `reconciliation`, `set_attendance`, `scoring`,
  `report_generation` and `finish_scan_session`; `live` decisions while files
  arrive, `late` after 60 %, `final` only after a refused closure.
* **Ground-truth evaluator**: `reference.py` scores, ranks (`RANK.EQ`),
  computes statuses, conflicts and report cells without calling any OMRFlow
  scoring, reconciliation, population or report function.

Full description: [`docs/intake_qualification.md`](../../../docs/intake_qualification.md).

The reference (`reference.py`) never calls OMRFlow's scoring,
reconciliation, population or report code. Compared, for the first close and
again after the reopen, in all three runs:

* **Attendance** - reconciliation statuses before and after the office's
  decisions (corrected attendance workbooks v2 / v3 assigned through
  `set_attendance`, duplicate scripts excluded, unknown IDs dismissed): equal.
* **Scores** - every scored candidate's stored result (status, mark, correct
  / wrong / blank / multiple counts) under +1 / −¼ / −¼ / 0, clamp 0, Set B
  Q7 withdrawn: equal (9,881 scored, 359 absent).
* **Rankings** - `RANK.EQ` formula values on each set's meritwise sheet
  (ties as Excel ranks them): equal.
* **Report values** - header labels and every row's Sl.No., Roll No., Name,
  Total (exact to 1e-9 or `ABSENT`) and Merit (`---` or the rank) on each
  set's rollwise and meritwise sheets, the empty row after the last, and the
  Answer Key sheet: equal. The Summary and Processing Log sheets carry
  timestamps and are not compared.
* **Effective population and Student IDs** - the session's effective sheets
  = the reference's 9,933 contents; effective IDs equal the paper's after
  corrections.

## 22. Known limitations

* **Synthetic, local disk, source build.** The images are generated; the
  scanners are processes; the outage is a local junction (reads fail as
  *file not found*; a real share fails with other errors and timings); it ran
  from source with the main checkout's virtual environment. It does **not**
  prove genuine SMB behaviour, real scanner behaviour, power-loss durability
  (process-kill crash safety: tested; power-loss durability: not tested),
  real-paper calibration of the quality policy (the unvalidated default),
  installed-build behaviour, or production readiness.
* **Headless.** The operator is scripted and decides from the paper's truth
  through the services; the operational GUI was not driven, and no person
  operated anything.
* **Progressive percentage series** in one run, not five independent
  projects as the Phase 10 finite harness does.
* **Writers are serial** (one file at a time per scanner), so the arrival
  period (≈ 3.2 h, 3.6 h including the late script after closing) is set by the partial-write pauses, not by the configured
  2,400 s schedule; recognition throughput in the continuous runs is
  therefore arrival-bound.
* **Supersession** was exercised once at release scale (*Reprocess All* of a
  1-sheet unit); an algorithmic re-read mid-session is not separately
  exercised.
* **Thresholds untouched**: recognition, quality (unvalidated default) and
  stability (production default) as shipped; no new threshold.
* **Project Health after a closed session** still warns about conflicts of
  rejected-and-replaced originals (54) and reconciliation exceptions of
  replaced attendance lists / decided entries (158); warnings only, not
  fixed here.
* **Run fragility**: the supervisor keeps run evidence in memory; a
  supervisor killed mid-campaign leaves no report (defects #10, #11). Launch
  release runs detached and hidden.
* **Windows only** for the release run; one machine; the gates ran while a
  campaign shared the machine.
* **Not tagged or released** (merged into `main` as `459c65b` on 2026-10-07).
