# Session mode — UI reference (0.1.1 revised phase 8)

Screenshots of the Scan stage's session mode and of Resolve while scanning,
captured on 2026-10-05 from the real main window on Windows at **175 %
display scaling**, window **1366×768** logical pixels, by
`.claude/skills/qtguitesting/scripts/capture_session_states.py`. The sheets are
the test suite's synthetic sheets read by the engine rig (fake disk and clock,
real recognition inline) - **not** a real scanning room, network share or
scanner. The full set (16 states, 1100×680 variants, the 80–200 % interface
zoom matrix and a geometry report) is regenerated by the script into the
git-ignored `test-output/gui/session_states/`.

| File | State |
|---|---|
| `03_processing.png` | Continuous scanning running: status line, three progress lines, counts |
| `07_source_unreachable.png` | *Waiting for Scanner C (unreachable since …)*; Sources section expanded |
